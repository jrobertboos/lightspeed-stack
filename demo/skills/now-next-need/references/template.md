# Now / Next / Need template

## Headings (this order, always all three)

```
## Now
## Next
## Need
```

Do not use Summary, Action items, Decisions, Notes, Owners, or Parking lot as headings.

## What goes where

| Heading | Content |
| --- | --- |
| Now | What is already true. Decisions already made. Current state. One short paragraph or bullets of facts. |
| Next | Work still to do. Each line is `- Owner: verb + object (date)`. |
| Need | Blockers, missing info, or asks of people not in the room. If nothing is blocked, write `- None.` |

## Owner line shape

```
- Priya: publish the blog post (May 12)
```

Name first, then a colon, then a verb. Never "blog post — Priya". If no owner was named, write `Unassigned`.

## Footer (required, last line)

```
Notes: now-next-need
```

## Forbidden

- Extra headings
- Emoji
- "Great meeting" or other filler
- Nesting bullets more than one level
